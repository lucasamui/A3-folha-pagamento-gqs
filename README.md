# Sistema de Folha de Pagamento

Trabalho Integrador (A1 e A3) da Unidade Curricular **Garantia da Qualidade de Software**.

## Objetivo

Sistema para cadastro e gerenciamento de colaboradores, cálculo automático das remunerações e geração da folha de pagamento individual e consolidada.

O sistema suporta três categorias de colaborador:

| Categoria | Cálculo do salário final |
|---|---|
| Padrão | Salário base |
| Comissionado | Salário base + (valor das vendas × percentual de comissão) |
| Produção | Salário base + (quantidade produzida × valor por unidade) |

## Tecnologias

- Java (JDK 17 ou superior)

## Como executar

```
cd 05_Codigo_Fonte
javac *.java
java Main
```
